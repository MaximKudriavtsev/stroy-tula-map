# План реализации: Пешая изохрона (10-15 минут)

## Цель
При клике на объект на карте подсвечивается зона, откуда до него можно дойти пешком за выбранное время (10 или 15 минут).

## Архитектура
- Используем Yandex Routing API v3 HTTP endpoint напрямую (не npm package)
- Тот же API key, что и для карты
- Time selector над картой
- ObjectCard оставляем минимальным

## Файлы для создания
1. `src/hooks/use-isochrone.ts` — хук для расчёта зоны через HTTP API
2. `src/components/isochrone-time-selector.tsx` — переключатель 10/15 мин
3. `src/components/isochrone-overlay.tsx` — отрисовка полигона на карте

## Файлы для модификации
1. `src/components/map-view.tsx` — добавить overlay, expose ymaps3 module
2. `src/app/page.tsx` — подключить state для изохроны

## Порядок шагов
