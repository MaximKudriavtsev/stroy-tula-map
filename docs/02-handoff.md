# Шаблон результата агента

Файл для заполнения исполнителем: docs/handoffs/Fxx.md, где Fxx — ID его задания.

## Что реализовано
Укажи ID, режим MVP/V2/TARGET и пользовательский результат. Отдельно перечисли недоступные внешние части.

## Изменённые файлы
Перечисли реальные пути, миграции, новую конфигурацию и её значения по умолчанию. Не включай секреты.

## Контракты и подключение
Укажи exports, API, events и точные строки подключения к composition root. Укажи совместимость с contracts v1 и изменения, требующие интегратора.

## Проверка
Приведи реально выполненные команды, exit code, число сценариев и существенный результат. Незапущенные проверки явно обозначь.

## Как посмотреть
Дай локальный маршрут, данные для тестового сценария из fixtures и ожидаемый результат. Тестовые пароли не должны быть production credentials.

## Передача следующей команде
Перечисли готовые входы, оставшиеся зависимости, известные ограничения и сценарий интеграции.
