# F00 — каркас и contracts v1

## Что реализовано

F00, режим **MVP**. Команда получает pnpm workspace, runtime-схемы contracts v1, OpenAPI, generated client, DEMO fixtures, mock API для public-web и admin-web, симулятор MessengerAdapter, health, DB client и реестр миграций без бизнес-таблиц соседних фич, контейнеры PostGIS/Redis/MinIO, команды из `docs/00-common.md`, базовый UI на русском и ADR.

Внешние системы (MAX, LLM, ПОС) не подключались и не выдаются за готовые.

## Изменённые файлы

Новый монорепозиторий поверх существующей документации:

- Корневые: `package.json`, `pnpm-workspace.yaml`, `pnpm-lock.yaml`, `tsconfig.base.json`, `eslint.config.js`, `vitest.config.ts`, `playwright.config.ts`, `.env.example`, `.env.production.example`
- `apps/api/**`, `apps/worker/**`, `apps/public-web/**`, `apps/admin-web/**`
- `packages/contracts/**`, `packages/api-client/**`, `packages/db/**`, `packages/fixtures/**`, `packages/ui/**`
- `infra/compose.yaml`
- `tools/{generate-contracts,run-feature-tests,seed-demo}.ts`
- `tests/{contracts,unit,integration,e2e}/F00-*`
- `docs/adr/0001-contracts-v1.md`

Миграции: `packages/db/migrations/F00/0001_registry.sql` (`schema_migrations`, `platform_heartbeat`).

Конфигурация по умолчанию (development): `API_MODE=mock`, `DATA_MODE=demo`, `ALLOW_DEV_ROUTES=true`, `ALLOW_SEED_DEMO=true`, `MESSENGER_ADAPTER=simulator`. Production-пример в `.env.production.example`.

## Контракты и подключение

- Exports: `@tula/contracts`, `@tula/api-client` (`createApiClient`), `@tula/fixtures`, `@tula/db` (`createDbClient`, `applyMigrations`), `@tula/ui`
- Префикс API `/api/v1`; health: `/health/live`, `/health/ready`
- Mock composition: `apps/api/src/platform/mock/{dispatch,http,server}.ts` подключается из `apps/api/src/app/create-app.ts`
- Frontend: `createApiClient({ baseUrl: '' })` + Vite proxy на `:3000`
- Совместимость: contracts **v1.0.0**. Изменения каталога endpoints — зона интегратора.

## Как посмотреть

```bash
cp .env.example .env
pnpm install --frozen-lockfile
pnpm dev
```

- Публичный сайт: http://localhost:5173 — список с «Демонстрационная школа А», баннер DEMO, слот карты
- Админка: http://localhost:5174 — таблица черновиков и форма
- API: http://localhost:3000/health/live и `/api/v1/public/objects?dataOrigin=DEMO`

Опционально: `pnpm infra:up && pnpm db:migrate` для PostGIS/Redis/MinIO. `pnpm seed:demo` в development только валидирует fixtures (таблиц объектов ещё нет).

Тестовых production-паролей нет.
